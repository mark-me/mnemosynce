Test Connections

Verify that your backup server can reach its sources, destinations, and email provider before running a backup.

SSH Connection

Tests reachability in three steps: ping, SSH login, and (optionally) whether a directory exists on the remote host.

Trust Host Key

Scans a remote host's public key and adds it to known_hosts so SSH connections from the backup server are trusted automatically. Run this once per host before testing the SSH connection.

Email (Gmail SMTP)

Connects to Gmail SMTP and sends a test email. The Gmail address and app password are read from the environment — no credentials needed here.
